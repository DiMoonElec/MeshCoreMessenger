# Универсальные модальные карточки и «О контакте»

Реализовано 04.10.2026. `ModalHostView` расположен над всем содержимым MainWindow:
затемнение, блокировка основного UI, неподвижная карточка по центру. Заголовок и
необязательные действия остаются на месте; произвольное содержимое прокручивается.
Размер ограничен доступной областью окна, цвета берутся из текущей темы.
Host не знает типов прикладных карточек: шаблоны содержимого регистрируются в MainWindow.

`ModalHostViewModel.ShowAsync(ModalCardViewModel)` возвращает `ModalResult` с причиной
закрытия и необязательным значением. На окно допускается одна карточка. Содержимое
задаёт заголовок, пояснение, список действий и `CanClose(reason)` — например, для
защиты несохранённых изменений. Крестик и Esc проходят через общий close policy.
Клик по затемнению по умолчанию не закрывает; включается через `CloseOnBackdrop`.
Shutdown принудительно освобождает содержимое и завершает ожидание результата.
Автоматической привязки Enter к действию нет; карточка контакта read-only.

Фокус переносится на крестик; Tab/Shift+Tab циклически обходят карточку. Горячие
клавиши chat/settings не выполняются под overlay. После закрытия восстанавливается
предыдущий доступный фокус (или последний фокус внутри основного окна, если меню
уже исчезло). Приём сообщений и фоновые сервисы продолжают работу.

В приватном меню «Подробности (тест)» заменён на «О контакте». Команда создаётся
при инициализации chat workspace, доступна при выбранном контакте с полным ключом,
включая offline. Публичное меню не получает этот пункт. При открытии захватываются
NodeId и полный ключ; последующая смена переписки
не переадресует карточку.

Сведения читаются через существующий `IConversationDirectoryReader`, без radio
команд и изменения схемы БД: имя, тип, публичный ключ, присутствие в справочнике,
маршрут, последний advert, координаты и время локального обновления. В техническом
разделе — флаги, дескриптор и сырое поле маршрута, сохранённый advert. Нулевые
координаты сопровождаются пояснением, отсутствующие данные не подменяются догадками.
Записи маршрута после commit обновляют открытую карточку только при совпадении
NodeId и полного ключа. Остальные сведения перечитываются при следующем открытии.
Ошибка чтения отображается в карточке с повтором. Закрытие отменяет чтение и
снимает подписку; устаревший результат не может заменить более новый.
