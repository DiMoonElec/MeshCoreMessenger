# Ручная UI-проверка MeshCoreMessenger C3 — 30.09.2026

## Среда и границы

- macOS, Avalonia Desktop;
- физическая MeshCore-нода подключена по сохранённому Serial-профилю `usb-node`;
- проверялся read-only UI C3; отправка, mutations и возможности C4+ не запускались.

## Подтверждённые сценарии

Пользователь сообщил, что интерфейс работает, и приложил два скриншота:

1. В широком окне отображаются отдельные вкладки «Личные», «Каналы», «Устройства».
   Во вкладке «Каналы» видны фильтр, несколько каналов, preview/время и история
   выбранного канала. Header отдельно показывает активный профиль и фактическую ноду.
2. В узком окне выбранный канал открывается отдельной detail-панелью; присутствует
   и работает предусмотренная навигация «Назад».
3. Редактор connection profile убран из постоянной левой колонки и доступен через
   кнопку «Настройки».

## Результат

C3 принят вручную. Скриншоты подтверждают основные wide/narrow сценарии поверх
реальной сохранённой истории физической ноды. Детерминированные тесты остаются
доказательством группировки, unknown/directories, node-scoped выбора, late-load
защиты и UI-dispatch. Визуальная полировка header и плотности относится к C9.
