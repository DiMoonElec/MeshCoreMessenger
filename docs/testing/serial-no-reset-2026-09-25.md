# Проверка Serial без сброса Heltec V3 — 25.09.2026

Проверка выполнена в 09:52 МСК через `/dev/cu.usbserial-0001` на ноде
`RnD CatCore🐈`. Использована пара `DTR=true`, `RTS=true`, безопасная для
стандартной двухтранзисторной схемы автосброса ESP32.

Ограничивающая обёртка разрешала только `APP_START` и `GET_STATS(core)`.
Очередь сообщений не читалась, радиопередачи и изменение настроек были запрещены.

В рамках одного теста порт открывался и закрывался дважды, между подключениями была
пауза три секунды:

| Подключение | Uptime |
| --- | ---: |
| Первое | 481 с |
| Второе | 484 с |

Uptime вырос ровно на длительность паузы. Закрытие и повторное открытие порта не
перезагрузили ноду; после каждого прохода `connected=false`. Всего выполнено четыре
локальные команды.

Предыдущие аппаратные harness-тесты использовали `DTR=false`, `RTS=false`.
`System.IO.Ports` применяет DTR и RTS последовательно после открытия. Для ESP32
переход к false/false может пройти через комбинацию, которая активирует `EN` и
даёт импульс сброса. Uptime первого безопасного прохода согласуется по времени с
перезагрузкой во время предыдущего открытия порта в 09:44:55 МСК.

После исправления значения по умолчанию и все аппаратные harness-тесты используют
`DTR=true`, `RTS=true`. Для плат с другой схемой линии остаются настраиваемыми.
