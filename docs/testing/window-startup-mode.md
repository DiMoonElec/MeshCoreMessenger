# Состояние окна после запуска

07.10.2026: по запросу пользователя в блоке «Поведение окна» добавлен список
«После запуска»: «Как последний раз» (по умолчанию), «Свёрнуто», «Свёрнуто в трей».

«Как последний раз» восстанавливает открытое, свёрнутое или скрытое в трее окно;
размер, положение и maximized state по-прежнему принадлежат существующему placement.
Режим и последнее фактическое состояние сохраняются раздельно через
`DesktopPreferences`/SQLite Settings и существующий background save/durable barrier.
Ключи `desktop.startup-window-mode` и `desktop.last-window-presentation` не требуют
миграции схемы. Отсутствующие/повреждённые значения дают LastState/Open.

Настройка применяется один раз при первом Opened, после восстановления геометрии,
до подключения queued activation. Первоначальный Show/Hide сохраняет прежний
startup hook `ConnectionLifecycle.StartAsync`; алгоритмы connect/reconnect не менялись.
При запуске «Свёрнуто» первоначальная минимизация не вызывает автоматический Hide
из S3. «Свёрнуто в трей» без доступного native tray безопасно заменяется обычной
минимизацией. Выбор режима в настройках влияет на следующий запуск, не скрывает
текущее окно.

Реальное состояние записывается после применения startup policy и при последующих
изменениях видимости/минимизации. Первоначальный Show не затирает предыдущее
состояние. Повторный Opened при возврате из трея не применяет настройку снова;
активация через S1, меню трея, macOS Reopen и notification click показывает окно
через общий `DesktopActivationCoordinator`, даже при выбранном фоне на старте.
Shutdown/teardown не записывает ложное состояние скрытого окна после принятия выхода.

## Проверки

- Release macOS сборка: 0 warnings/errors; Desktop **400/400**.
- Настройки: reload обеих величин, независимое изменение последнего состояния,
  повреждённые данные, failed save → newest value → retry.
- Native Avalonia `--startup-window-only`: LastState × Open/Minimized/Tray,
  Minimized при предыдущем Tray, Tray при предыдущем Open, Tray unavailable fallback.
  Во всех шести случаях состояние после Show, запись реальной SQLite и восстановление
  через activation прошли. Connect calls — 0 (изолированный audit, autoconnect выключен).
- Windows GUI-граф скомпилирован без предупреждений/ошибок с прежними временными cross-build параметрами;
  это не визуальная проверка Windows. Ручная приёмка Windows ожидается.

Ручная проверка: выбрать каждый вариант, полностью выйти через меню трея «Выйти»
и запустить снова. Для LastState отдельно проверить выход из открытого окна, из
обычной минимизации и из трея. В последних двух случаях проверить вторую попытку
запуска/меню «Открыть» и click по уведомлению: окно должно появиться. Проверить
сохранение размера/положения и maximized состояния, приём сообщений в фоне,
автоподключение и нормальный выход со скрытым окном.
