# Выделенная Serial-нода для разработки

Дата подтверждения пользователем: 25.09.2026.

Пользователь явно разрешил coding-агентам подключаться к специально выделенной
тестовой MeshCore Companion-ноде на этом ПК для разработки и аппаратных проверок.
Текущий порт: `/dev/cu.usbserial-0001`; перед запуском следует убедиться, что он
по-прежнему присутствует в списке Serial-портов.

Для этой Heltec V3 использовать проверенные параметры `115200`, `DTR=true`,
`RTS=true`, open delay 2 секунды. Эта пара уже проверена без сброса ноды; не заменять
её на `DTR=false`/`RTS=false`, поскольку последовательное применение false/false
раньше могло дать импульс аппаратного сброса. Не переключать линии повторно после
открытия и не использовать reset как проверку соединения.

Само подключение, `APP_START`, локальные запросы и чтение данных ноды разрешены без
дополнительного согласования. Это постоянное разрешение на доступ к тестовой
аппаратуре в рамках разработки данного проекта.

Радиопередачи, изменение контактов/каналов и другие изменения состояния ноды должны
соответствовать текущему заданию пользователя. Разрешение на подключение само по себе
не означает разрешение на произвольную передачу в эфир. Каждый аппаратный отчёт
должен фиксировать фактически выполненные команды и отдельно указывать наличие либо
отсутствие RF-команд.
