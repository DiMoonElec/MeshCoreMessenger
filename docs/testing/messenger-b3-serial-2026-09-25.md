# Аппаратная проверка MeshCoreMessenger B3 — 25.09.2026

Проверка выполнена на выделенной пользователем тестовой ноде через
`/dev/cu.usbserial-0001` с `115200`, `DTR=true`, `RTS=true` и open delay 2 секунды.

Harness создал временную БД, идентифицировал ноду, затем запустил `DirectoryService`.
Разрешённые команды: `APP_START`, получение списка контактов, локальный запрос
сведений о Companion для определения ёмкости каналов и чтение channel slots. Очередь
сообщений не читалась. Изменения контактов/каналов, передачи в эфир и другие RF-команды
не выполнялись.

Результат:

- полный снимок содержал 117 контактов;
- были сохранены 4 активные привязки channel slots;
- pending transitions не возникли (`0`): текущий снимок согласован с пустой временной
  историей привязок;
- каждая запись канала получила только SHA-256 fingerprint секрета; сами секреты не
  выводились и временная БД была удалена после проверки;
- сессия штатно остановлена с причиной `B3 hardware verification completed`;
- после завершения `lsof /dev/cu.usbserial-0001` не обнаружил владельца порта.

Процесс завершился с кодом 0. Постоянная БД пользователя и состояние ноды не изменялись.
