о разработке кода. Проверка выполнена в 20:08 MSK через `/dev/cu.usbserial-0001`.
Нода `RnD CatCore🐈`, ранее определённая как Heltec V3 с прошивкой v1.17.1-d929643.

Тест использовал публичный `MeshCoreClient.SendChannelTextAsync` и ограничивающую

`#test` (индекс 1). Обёртка допускала единственную команду канальной передачи
с фиксированным текстом; личные сообщения, объявления и запись настроек запрещены.

Явный запуск этого теста повторно отправит ещё одно такое сообщение:

```bash
dotnet run --project tests/MeshCoreSharp.Tests -c Release -- --serial-send-test /dev/cu.usbserial-0001
```

Параметры Serial: 115200/8N1, DTR=false, RTS=false, задержка открытия 2 секунды.
Автоматическое чтение очереди сообщений отключено. При ошибке после начала отправки
тест завершается и не пытается повторно передать сообщение.

Позднее обнаружено, что пара DTR=false/RTS=false могла сбрасывать ESP32 при открытии.
Текущие harness-тесты используют DTR=true/RTS=true; отсутствие сброса подтверждено
[отдельной проверкой](serial-no-reset-2026-09-25.md).
