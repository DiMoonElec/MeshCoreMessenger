# Регионы: поиск, каталог и отправка

Регион задаёт область распространения исходящих flood-сообщений через репитеры.
Он не меняет частоту, ключ канала или список участников. Для практического
использования нужны ближайшие репитеры, которые поддерживают выбранный регион.

## Найти и сохранить регионы

1. Подключитесь к Companion-ноде и дождитесь готовности подключения.
2. Откройте «Настройки» и нажмите «Поиск регионов».
3. Пока движется бегунок, идёт поиск. Первые 30 секунд приложение собирает ответы
   прямых соседей, затем опрашивает до четырёх репитеров с самым сильным сигналом.
   Ожидание и повторные запросы могут занять ещё несколько минут.
4. Полученные регионы появляются в общем списке с уже сохранёнными.
5. Нажмите `+` справа от региона, чтобы сохранить его в каталоге.

Кнопка «Отмена» прекращает дальнейший поиск. Полученные строки остаются в списке;
завершение отмены может занять немного времени для восстановления маршрута ноды.
Пустой результат не доказывает отсутствие репитеров: ответы могут теряться из-за
коллизий, условий связи или ограничения частоты запросов. Поиск можно повторить.
Повторный запуск дополняет видимый список, не очищая его.

Список не сохраняется целиком автоматически. При уходе из настроек несохранённые
строки исчезают. При следующем открытии показывается каталог из БД текущей ноды.
Каталог разных собственных нод хранится раздельно и доступен offline.

## Удалить регион

У сохранённого региона справа показан `−`. Нажатие удаляет его из каталога и
меняет кнопку на `+`. Строка остаётся до ухода из настроек, поэтому её можно
добавить обратно. При следующем открытии удалённого региона уже нет в каталоге.

Если регион назначен каналу, приложение не даст его удалить. Сначала измените
регион соответствующего канала. Удаление из каталога не редактирует список
регионов на репитере и не очищает автоматически default ноды.

`*` означает отсутствие региона и не добавляется отдельной строкой. Новые
приватные имена `$…` без ключа в список добавления не попадают: по имени получить
ключ нельзя. Ранее сохранённые private/custom записи остаются доступны.

## Default ноды

В отдельной карточке «Регион по умолчанию на ноде» выберите сохранённый регион
и нажмите «Применить к ноде». Кнопка «Без региона» очищает default.
Изменение выполняется только при подключении; offline приложение показывает
последнее наблюдение. «Неизвестен» не означает «без региона».

Default используется каналами с выбором «Как у ноды» и обычными ЛС при
flood-отправке. Проверка ЛС с регионами на реальной сети отложена: методика
будет согласована отдельно. Подключение/reconnect само не записывает default
и не повторяет старые сообщения.

## Регион канала

Откройте канал. Под его названием показан действующий регион.
В меню `⋯` → «Регион отправки» выберите:

- «Как у ноды» — использовать default подключённой ноды;
- «Без региона» — отправлять без scope независимо от default;
- сохранённый регион — отправлять в этот регион.

Настройка относится к этому каналу на этой собственной ноде. Она не изменяет
название канала, его секрет, историю и черновик. Входящим сообщениям текущий
выбранный регион не приписывается: протокол истории не сообщает его достоверно.

Приложение пересчитывает доступные UTF-8 байты с учётом выбранного региона и
транспорта. Превышение лимита блокирует отправку, текст не обрезается.
Принятие канального сообщения нодой не является подтверждением получения
удалённой нодой: у канала нет ACK доставки.

## Повтор сообщения

«Повторить доставку» канального сообщения использует сохранённый scope исходной
попытки. Последующая смена региона канала не переносит такой повтор в новый
регион. «Отправить как новое» использует текущую настройку канала и новый timestamp.
Для старых сообщений, у которых scope не был сохранён, точный повтор может
быть недоступен; осознанная новая отправка может создать дубликат у получателя.

## Совместимость и границы проверки

Каталог и назначения каналам хранятся в БД Messenger. Другое приложение Companion
их автоматически не увидит. Default хранится на ноде и может меняться другим
клиентом; после внешних изменений переподключитесь для чтения состояния.

В предыдущих аппаратных проверках использована CatCore/Heltec V3 с Companion
`v1.18.0-07a833bb`, protocol14. Поддержка каждой команды определяется возможностями
конкретной прошивки, а не только названием версии. Запрос регионов доступен без
пароля администратора, но не даёт ключей приватных регионов и полного дерева
настроек репитера. Поиск не обходит всю mesh-сеть.

Temporary scope глобален в прошивке. Клиент сериализует свои команды и сбрасывает
его после отправки, однако автономный PATH/ACK прошивки может попасть в это окно.
Этот случай и аппаратная работа ЛС с регионами пока не проверены.
