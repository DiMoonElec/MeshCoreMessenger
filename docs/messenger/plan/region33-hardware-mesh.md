## Шаги

1. Проверить neighbours→regions, известный direct/flood contact, последствия addContact/route restore; записать фактические capabilities репитера.
2. Передать помеченные тестовые сообщения channel A/B и ЛС с разными scopes; проверить принимающую сторону, direct/flood ACK и восстановление после disconnect без replay.
3. Отдельно исследовать incoming ЛС во время temporary channel override; если окно не воспроизведено, зафиксировать как непроверенное. Восстановить все изменённые настройки/пути условно без перезаписи новых данных.

**За границами шага:** Вывод об отсутствии гонки по одному удачному тесту; обход согласования радиосценария.

## Проверки и завершение

**Обязательные проверки:** Scoped/unscoped/default; текст и ACK отдельно; valid scopes обоих направлений; full/partial discovery; транспортные границы; crash/cleanup uncertainty в контролируемом сценарии.

**Готово:** Проверки и остаточные firmware ограничения зафиксированы без заявления об абсолютной изоляции ACK.

Если зависимость отсутствует или проверка не выполнена, записать точную причину и
оставить соответствующий пункт открытым. Для аппаратных/GUI проверок различать
автоматический результат, native просмотр и пользовательское подтверждение.
Не объявлять всю REGION завершённой по успеху одного слоя.

- [x] Ручные результаты поиска/каталога/каналов записаны, согласованный объём зафиксирован.
- [ ] Полная исходная RF-матрица, включая ЛС/ACK/temporary override race, выполнена — отложено.
- [x] Ограничения и оставшиеся проверки указаны.
- [x] Статус этого файла, checklist Stage REGION и current-state обновлены.
