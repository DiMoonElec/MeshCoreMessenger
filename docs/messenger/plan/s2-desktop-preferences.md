# S2 — поведение крестика и настройки уведомлений

[Stage S](stage-s.md) · **Статус: не начат.**

**Цель:** три понятные настройки в существующем экране, без сложных фильтров.

**Scope:** аддитивно расширить `DesktopPreferences` и `ApplicationSettingsView`:
выбор «Сворачивать в трей» / «Закрывать приложение» и два чекбокса
«Уведомления для личных сообщений» / «Уведомления для каналов».
Крестик по умолчанию скрывает в трей. Рекомендуемые начальные значения чекбоксов —
оба включены. Новые ключи через существующий `ISettingsStore`, без таблиц/миграции.

Отсутствующие/невалидные значения читаются с безопасными defaults; прежняя тема
и window placement сохраняются. Изменения сразу обновляют snapshot для S3/S5.
Предусмотреть сохранение изменённых настроек во время жизни приложения:
после добавления трея пользователь может долго не выполнять настоящий выход.
Сохранить durable dirty/retry/flush семантику и существующий shutdown barrier;
ошибки записи не скрывать, повтор сохранения не вызывает сетевые действия.

До S3/S6 экран честно обозначает ещё не подключённые возможности либо вводится
частями вместе с соответствующей production-интеграцией. Чекбокс предпочтения
не является доказательством разрешения уведомлений со стороны ОС.

**Не входит:** отдельные настройки контактов/каналов, mute, расписания, фильтры,
звуки, настройка reconnect или новый settings subsystem.
**Зависимости:** [C9](c9-preferences.md), DesktopPreferences/ISettingsStore,
существующий ApplicationSettingsView. Другие подэтапы S не требуются.

**Тесты:** старая БД без ключей, invalid values, apply/save/reopen, быстрые изменения
во время flush, persistence failure/retry и shutdown barrier; независимость папок;
прежняя тема/геометрия не меняются. Проверка доступности controls и binding.

**Готово:** три параметра имеют определённые defaults, применяются без перезапуска,
надёжно сохраняются; production поведение включается в S3/S6.
**Ручная проверка: обязательна** — narrow/wide, Light/Dark, keyboard/Tab,
понятные подписи и восстановление после перезапуска.
