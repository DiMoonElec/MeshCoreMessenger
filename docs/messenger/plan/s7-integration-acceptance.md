# S7 — совместная приёмка desktop-интеграции

[Stage S](stage-s.md) · **Статус: не начат.**

**Цель:** подтвердить совместную работу single-instance, трея, настроек и уведомлений
без регрессии сохранности, unread и существующего connection lifecycle.

**Scope:** интеграционные проверки, self-contained native приёмка macOS/Windows,
короткое обновление пользовательской инструкции и отчёт в docs/testing.
Использовать временную/копию БД и fake session для автоматических сценариев;
тестовые радиопередачи не следуют из этого этапа и требуют отдельного согласования.

**Не входит:** закрытие всех критериев Stage D/E, новые connection/retry policies,
полная приёмка Linux/других архитектур или необоснованный рефакторинг.
**Зависимости:** S1–S6; ранее реализованные shutdown/draft/read/preferences contracts.
Непринятые платформенные части S6 остаются явными открытыми пунктами, не скрываются
за успешной сборкой или fake adapter.

## Обязательная матрица

- [ ] Открытый/неактивный/свёрнутый/скрытый экземпляр + повторный запуск:
  один владелец БД, существующее окно показано.
- [ ] Одновременный старт, запуск до готовности UI, серия запусков, crash/restart,
  повторный запуск во время shutdown и ошибка startup.
- [ ] Стандартная/нестандартная/эквивалентная папка и две разные папки:
  активация правильного владельца, настройки/история независимы.
- [ ] Крестик в обоих режимах, minimize, tray Open/Exit, macOS reopen/Quit/Cmd+Q,
  OS shutdown; отсутствие доступного tray имеет рабочий fallback.
- [ ] Выбранная переписка, черновик, scroll и normal/maximized placement сохраняются;
  hidden/minimized не гасит unread, Show не повторяет startup/connect.
- [ ] Соединение/приём продолжаются в фоне; existing reconnect regressions проходят.
  Показ окна/click не отправляет сообщения и не меняет конфигурацию.
- [ ] Shutdown persistence failure из скрытого окна возвращает доступную ошибку;
  retry сохраняет без radio replay; после выхода лок/IPC освобождены.
- [ ] Четыре сочетания чекбоксов, настройка/restart, отказ разрешения ОС, DND;
  ЛС/каналы/unknown/binary, просмотренное сообщение и фоновые входящие.
- [ ] Burst/initial backlog/reconnect/delayed commit/dedup: разумное число баннеров,
  история и unread не теряются; ошибка платформы не блокирует ingest.
- [ ] Click при running/cold start/tray, разные папки/node contexts, удалённая цель
  и старый баннер: правильный переход либо понятный fallback, без connect/mutation.
- [ ] «Каналы»/«Чаты» во всех актуальных текстах, обе темы, narrow/wide и keyboard.
- [ ] Self-contained .app/portable на реальных ОС; записаны ОС/архитектура,
  формат пакета, способ регистрации, разрешения и непроверенные ограничения.

**Готово:** релевантные Core/Desktop regression suites и Release build проходят,
ручная матрица имеет фактические результаты; инструкция объясняет трей, полный
выход, повторный запуск и два переключателя.
Статусы подэтапов/current-state обновлены без переписывания исторических checkpoints.
**Ручная проверка: обязательна.** Сборка и unit tests не заменяют проверку native tray,
foreground activation, разрешений и click handlers на целевой ОС.
