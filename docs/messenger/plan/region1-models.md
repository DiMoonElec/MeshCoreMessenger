## Шаги

1. Ввести InheritDefault / ExplicitRegion / ForceUnscoped, immutable key16 и модель прочитанного default с различием KnownEmpty и Unknown.
2. Реализовать public derivation с одним служебным #, точным UTF-8 и сохранением регистра; отделить custom key и отклонить all-zero explicit key.
3. Проверять длины полей по байтам, NUL, специальные имена и копирование входных массивов; не связывать RegionDefinition библиотеки с БД.

**За границами шага:** Команды, runtime, SQLite и GUI.

## Проверки и завершение

**Обязательные проверки:** Известные SHA256-векторы; name/#name; регистр; Unicode и 30-byte граница default; неверный key; изменение исходного массива.

**Готово:** Модели и derivation готовы для wire API; сетевых команд нет.
