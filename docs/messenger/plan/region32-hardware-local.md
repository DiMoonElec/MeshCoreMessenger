## Шаги

1. Зафиксировать node/firmware hash/protocol и доступные TCP/Serial/BLE; сохранить исходный default в локальный защищённый capture.
2. По согласованному сценарию выполнить GET/SET/CLEAR/readback, reboot persistence и восстановить исходный default; возможные firmware autoadverts учитывать при подготовке.
3. Проверить reconnect без implicit SET/replay и общую identity разных транспортов; недоступные transports пометить pending с причиной.

**За границами шага:** Несогласованные радиопередачи, сбросы настроек и использование production DB для эксперимента.

## Проверки и завершение

**Обязательные проверки:** Фактические значения до/после; restoration readback; reboot persistence; unsupported/mismatch; реальные кадры и версия без key material в публичном отчёте.

**Готово:** Результаты воспроизводимы и исходная конфигурация восстановлена либо явно отмечена unresolved.

Если зависимость отсутствует или проверка не выполнена, записать точную причину и
оставить соответствующий пункт открытым. Для аппаратных/GUI проверок различать
автоматический результат, native просмотр и пользовательское подтверждение.
Не объявлять всю REGION завершённой по успеху одного слоя.

- [x] Результаты доступных проверок записаны, согласованный объём зафиксирован.
- [ ] Полная исходная матрица GET/SET/CLEAR/reboot/transport parity выполнена — отложено.
- [x] Ограничения и оставшиеся проверки указаны.
- [x] Статус этого файла, checklist Stage REGION и current-state обновлены.
