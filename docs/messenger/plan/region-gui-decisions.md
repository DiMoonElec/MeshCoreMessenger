# REGION26 — согласованные решения GUI

17.10.2026 пользователь согласовал расположение и явно поручил реализацию.

- «Настройки»: карточка поиска регионов и добавления в локальный каталог;
  отдельная карточка default региона ноды. Discovery пока находится здесь как временное решение.
- Под названием канала показывать действующий регион: `Регион: ru-ros`,
  `Регион: без региона`, либо `Регион: неизвестен`. Для наследования добавлять `(как у ноды)`.
- Меню ⋯ → «Регион отправки»: «Как у ноды», «Без региона», выбор из каталога.
  Политика сохраняется для channel identity текущей ноды и применяется MessageService.
- Каталог/назначение доступны offline; изменение default и discovery — только
  для текущей Online-ноды. Offline default явно обозначается последним наблюдением.
  Неизвестное и неподдерживаемое состояние не выдаётся за «без региона».
- Поиск только по кнопке, с прогрессом/отменой и явным разрешением побочных действий
  добавления контактов/временного zero-hop. Результат не назначается и не сохраняется
  автоматически; пользователь отдельно добавляет выбранное имя. Частный регион требует ключа.
- Удаление назначенного региона запрещено Core; UI объясняет необходимость сменить
  назначения. Архивирование сохраняет старые назначения и историю.
- Отдельный новый UI истории scope и per-contact region не добавляется. Текущие
  repeat/as-new и immutable captures сохраняются. Бюджет composer следует выбранной политике.

Реализация: REGION27 — локальный каталог в Settings; REGION28 — default и заголовок/
выбор канала; REGION29 — поиск в карточке; REGION30 — актуализация budget и UI при смене
scope без новых history controls. Проверки UI и lifecycle сохраняют границы REGION31.
