# Оформление упоминаний в чате

[UI2 — чат](ui2-chat.md) · [Текущий статус](current-state.md)

Этот файл описывает первоначальный Run-вариант. Последующая согласованная
доработка заменяет его: [rounded chips и копирование сообщения](chat-mention-chips.md).

Реализовано после UI3 по согласованному плану. Ручная визуальная приёмка ожидается.

## Поведение и границы

Полный фрагмент `@[имя]` получает вторичный foreground/background темы; точное
Ordinal-совпадение с исходным именем ViewedNode — акцентные цвета. Регистр, пробелы
и Unicode не нормализуются. Имя из header с ключом и fallback «Нода без имени»
не участвуют. Online ViewedNode соответствует session, offline остаётся последняя
история; disconnect не снимает подсветку своих упоминаний. Это совпадение текста,
не доказательство identity автора/получателя и не адрес для отправки.

Пустые/whitespace-only имена, вложенные скобки, переносы строки внутри конструкции
и незакрытые упоминания остаются обычным текстом. Формат не имеет экранирования:
имена с квадратными скобками нельзя однозначно представить как `@[имя]`.
Кириллица, emoji и пробелы в обычных именах поддерживаются.
Подсветка только в теле открытой переписки: preview, search results, composer,
автодополнение и действия по клику не менялись.

## Изменённые файлы

- `Desktop/Presentation/MentionParser.cs` — чистый линейный разбор сегментов;
  конкатенация сегментов всегда восстанавливает оригинальный текст.
- `Desktop/Controls/MentionTextBlock.cs` — SelectableTextBlock с Run без embedded
  controls; смена текста очищает старые spans/selection, смена имени сохраняет
  диапазон selection, обновление кистей не перестраивает runs.
- `Views/Chat/ConversationView.axaml` — bindings Body и исходного имени ViewedNode.
- `Styles/ConversationStyles.axaml`, `ThemeResources.axaml` — локальный стиль и
  четыре семантические кисти в каждой из Light/Dark, без цветов в view/control.
- `ViewModels/MainWindowViewModel.cs` — **+2 строки** в KnownNodeListItem:
  nullable MentionName сохраняет исходное имя без подмены fallback.
- `Desktop.Tests/MentionTests.cs` — 16 новых детерминированных тестов.

Core, schema, protocol, supervisor и history/navigation ViewModels не менялись.
Нет перезаписи сообщений, пересоздания списка, подключения транспорта, send/advert.
Существующая виртуализация и visible-range/read-state contracts сохранены.
