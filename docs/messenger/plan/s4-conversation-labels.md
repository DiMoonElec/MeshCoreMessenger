# S4 — «Каналы» и «Чаты» во всём интерфейсе

[Stage S](stage-s.md) · **Статус: не начат.**

**Цель:** привычные короткие названия без изменения идентичности и поведения переписок.

**Scope:** «Публичные чаты» → «Каналы», «Приватные чаты» → «Чаты».
Проверить не только NavigationShellViewModel, но и заголовки, поиск, подсказки,
пустые состояния, back/load-more, диалоги, accessibility names и актуальную
пользовательскую инструкцию. Общие ChatsView/ConversationListView получают
необходимые контекстные подписи через существующие VM:
«Поиск каналов» / «Поиск чатов», «Ещё каналы» / «Ещё чаты», возврат к нужному списку.

Менять только пользовательскую терминологию. Внутренние PublicChats/PrivateChats,
storage enum values, ключи preferences и identities можно оставить.
«Публичный / hashtag» — характеристика доступа канала, а не прежнее название
раздела; смысл этой характеристики сохраняется.
Исторические checkpoints не переписывать как будто новые названия были изначально.

**Не входит:** переименование всех классов/namespace, миграция БД, новая навигация,
фильтры/группировки каналов, смена contact/channel identity.
**Зависимости:** существующие shell и два workspace; S1–S3/S5–S6 не требуются.
Можно выполнить отдельным первым UI-изменением, если пользователь выберет S4.

**Проверки:** адресный поиск прежних UI-формулировок в source и текущей инструкции,
осмотр всех затронутых экранов; существующие navigation/workspace regressions.
Не добавлять тесты, только повторяющие каждую строковую замену; адаптировать
затронутые ожидания и проверять контекст общих controls.

**Готово:** названия согласованы во всём актуальном интерфейсе и инструкции,
переключение workspace/selection/draft/history работает как прежде.
**Ручная проверка: обязательна** — оба раздела, empty/search/list/detail/menu,
narrow/wide и обе темы.
